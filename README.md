# 🐻 Doudou Talking

Un doudou gris qui répète tout ce que tu dis, comme Talking Tom ! 🗣️

✅ Build automatique de l'APK Debug directement sur GitHub
✅ Compatible Android 7.0+ (API 24)
✅ Parle en français

## 📥 Télécharger l'APK
Va dans l'onglet **Actions → Build Debug APK → clique sur le dernier run → Artifacts → DoudouTalking-APK**
